# Asset provenance

All gameplay source, geometry, creature design, shaders and sound synthesis in this project were created for The Still Below. No assets, characters, recordings, music tracks or textures from existing games are used.

Geometry is generated from Godot primitive meshes. Tile and water surfaces are mathematical shaders. Audio is synthesized from oscillators, envelopes and seeded noise directly into Godot audio streams. Interface typography uses the engine's bundled default font, under its upstream license; no external font files are included. Godot itself is a separate open-source engine under its upstream license.

The poolrooms setting is a genre inspiration. This prototype does not recreate a specific existing game's characters, maps or assets.
